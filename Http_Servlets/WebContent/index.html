Hello World

This page is a static file served by Tomcat's DefaultServlet. Everything below is handled by the servlets of this project: Tomcat parses the HTTP request, finds the servlet by URL and calls its doGet / doPost.

GET/first

FirstServlet, mapped in web.xml. Writes a line with resp.getWriter().

Open /first

GET/first?param=…

Query parameters: getParameter and getParameterMap.

Open with parameters

GET/first?headers

All request headers your browser sent: getHeaderNames.

Show my headers

GET/download

DownloadServlet, mapped with @WebServlet. Content-Disposition: attachment makes the browser save the file.

Download filename.json

POST/first (form)

A regular form: the browser sends name=... URL-encoded, the servlet reads it as a parameter.

POST/first (text body)

enctype="text/plain": the text is not a parameter, the servlet reads it from the body with req.getReader().
